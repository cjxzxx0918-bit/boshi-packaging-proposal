# 博士瓶包装提案

四类盒型、六色配套的包装方案预览，包含效果图、空白盒型和配套平面稿。

## 在线预览

[打开博士瓶包装提案](https://cjxzxx0918-bit.github.io/boshi-packaging-proposal/)

进入页面后，可按盒型、排版方案、颜色、规格和视角选择；点击图片可查看大图，平面稿支持下载。点击“复制当前方案链接”可分享当前选择。

## 文件说明

- `index.html`：合集首页。
- `assets/preview/`：浏览预览图。
- `assets/full/`：效果图大图。
- `assets/artworks/`：平面稿原图。

完整下载后，解压并打开 `index.html` 也可离线浏览，请保留 `assets` 文件夹。

本仓库用于方案展示。
